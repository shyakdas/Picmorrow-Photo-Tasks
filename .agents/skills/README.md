# Android Agent Skills

This directory contains a project-focused selection of Google's official
[Android skills](https://github.com/android/skills), installed from the `main`
branch on 2026-09-30.

Installed skills:

- `android-permissions-security`
- `camerax`
- `edge-to-edge`
- `play-policy-insights`
- `styles`
- `testing-setup`
